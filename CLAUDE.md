## Sobre este projeto

Site institucional da BS Agro Capital: HTML puro, Tailwind CSS via CDN + CSS
customizado em `assets/styles.css`, JavaScript vanilla embutido em `<script>`
no fim de cada página, e Lenis via CDN para o scroll suave. **Sem framework,
sem etapa de build.** Ver o `README.md` na raiz para a documentação completa
(stack, estrutura, sistema de design, pendências antes de publicar).

## Development

Para ver o site rodando localmente:

```
node dev-server.cjs
```

Abre em `http://localhost:4321`. É um servidor estático mínimo, só para
desenvolvimento — não é necessário para publicar (qualquer hospedagem
estática serve os arquivos direto).
